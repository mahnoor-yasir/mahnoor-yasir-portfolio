# Mahnoor Yasir — Professional Portfolio

A responsive recruiter-focused portfolio built with semantic HTML, CSS, and vanilla JavaScript. No framework, installation, server, or build step is required.

## Open the website

1. Extract the ZIP file.
2. Keep all files and the `assets` folder together.
3. Double-click `index.html`.

## Included

- Clean text-only project cards with All, Web, Games, AI & Data, Software, and Hardware filters
- 12 selected projects with verified GitHub links and playable itch.io links for games
- Internship experience with supporting repository links
- Moving 3D carousel with 37 relevant web, Unity, AI/data, programming, developer-tool, and creative skills
- 85 text-only credential cards with local certificate files
- BSCS, Intermediate (ICS), and Matric education
- Theme-matched contact form connected to Formspree, plus direct email, phone, GitHub, LinkedIn, and itch.io links
- Responsive desktop, tablet, and mobile layouts

## Main files

- `index.html` — portfolio structure and content
- `style.css` — original dark visual system
- `overrides.css` — final project, education, contact, and footer refinements
- `script.js` — project filters, certificate filters, moving skills carousel, navigation, animations, and contact form
- `assets/` — CV, resume, certificates, internship documents, workshops, competitions, and volunteering records

The contact form submits securely to the configured Formspree endpoint.
